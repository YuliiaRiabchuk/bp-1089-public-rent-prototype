# BP-1089 —  сторінка самообслуговування прототип

Клієнт заходить за своїм номером, бачить усі свої оренди, продовжує
строк і платить — без дзвінка менеджеру. Прототип клікабельний: усі екрани,
переходи й помилки справжні, дані фейкові.

## Модель входу

Не «одне посилання = одна оренда». Адреса `/o` — одна на всіх, її можна
переслати в чат, і вона нічого не відкриває. Пускає код, який приходить на
номер. Тому посилання не протухає і не є секретом; секрет — код.

## Демо-код і номер

| Що             | Значення      |
| -------------- | ------------- |
| Номер          | `0671234567`  |
| Код із SMS     | `424242`      |

Код живе 5 хвилин, 5 невдалих спроб блокують вхід на 15 хвилин, повторна
відправка — не частіше разу на хвилину. Це не декорація: обмеження працюють,
щоб їх було видно на демо.

## Сценарії

Набір даних вибирається адресою: `/o/<ключ>`.

| Адреса         | Що показує                                     |
| -------------- | ---------------------------------------------- |
| `/o/demo`      | Базовий — три оренди на одному номері          |
| `/o/single`    | Одна оренда, список пропускається               |
| `/o/deposit`   | Застава покриває доплату                        |
| `/o/balance`   | Є баланс контрагента — 2 500 ₴                  |
| `/o/holiday`   | Продовження через свято (коефіцієнт 0,5)        |
| `/o/busy`      | Дати зайняті — заявка менеджеру                 |
| `/o/dupes`     | Два контрагенти на одному номері (ФО + ЮО)      |
| `/o/blocked`   | ЧС — тільки перегляд                            |
| `/o/empty`     | Активних оренд немає                            |
| `/o/unknown`   | Номера немає в базі                             |
| `/o/gateway`   | Шлюз кодів недоступний                          |

Стан живе у вкладці: перезавантаження сторінки повертає сценарій на початок.

## Дві розвилки оплати

Намальовані обидві, щоб вибір робився з макетів, а не з опису:

- **А** — переказ за реквізитами ФОПа. Комісії немає, клієнт вводить суму й
  призначення руками, оплату підтверджує людина.
- **Б** — карткою через провайдера (Apple / Google Pay). З чека 1 000 ₴ комісія
  13–15 ₴: LiqPay 1,5 %, plata by mono 1,3 %.

На екрані різниця — один рядок у списку способів. До рішення на користь Б треба
закрити ПРРО й розбіжність суми через утриману комісію — обидва питання до
бухгалтерії.

## Дані

Усі реквізити вигадані. Прізвища ФОПів, IBAN, ІПН і телефони відділень —
заглушки (`ФОП Кравченко І. П.`, `UA0000…`, `+380 (44) 000-00-01`). Сторінка
показує реквізити клієнту для переказу, тобто їх бачить кожен, хто відкриє
посилання. Реальні сюди не повертаємо.

## Запуск локально

```bash
npm install
npm run dev
```

Відкрити http://localhost:5173/o/demo

Бекенда немає: усі відповіді дає MSW (`src/mocks/`), який працює і в
продакшн-збірці — це сам сервер прототипу, а не інструмент розробки.

## Деплой

GitHub Pages, воркфлоу `.github/workflows/deploy.yml`. Пуш у `main` збирає й
викочує сам; нічого запускати руками не треба.

Дві речі, які Pages нав'язує і які видно в коді:

- сайт живе в `/<repo>/`, а не в корені. Звідси `BASE_PATH` у збірці, префікс
  `BASE_URL` у шляхах моків (інакше service worker MSW не перехопить запити —
  вони вийдуть за його scope) і відлік сегмента датасету від бази;
- SPA-rewrite Pages не вміє, тому воркфлоу кладе поруч `404.html` — копію
  `index.html`. Без неї `/o/holiday` прямим посиланням віддавав би 404.

Репозиторій публічний: на безкоштовному тарифі Pages з приватного не працює.
Тому в коді немає нічого, крім цього екрана, а всі реквізити — заглушки.

## Звідки код

Витяг з робочої гілки основної системи, де сторінка живе на роутах `/o` і
`/o/$token`. Сюди перенесено саму фічу (`src/features/public-rent/`), її моки й
токени дизайн-системи — без решти застосунку.
